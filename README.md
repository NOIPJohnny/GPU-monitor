# GPU Monitor

[English](README.en.md)

一个用于通过 SSH 查询多台机器 GPU 状态的 Flutter 桌面小工具。

![interface](assets/interface.png)

## 功能

- 从 `~/.ssh/config` 读取主机配置。
- 通过 SSH 执行 `nvidia-smi`，查询 GPU 利用率、显存、温度和功耗。
- 按主机展示查询结果，并区分正常、无 GPU、错误和加载状态。
- 在每张 GPU 卡片底部折叠展示进程详情，包括 PID、用户、显存占用、运行时间和命令行。
- 在支持的 Linux 主机上展示进程级 SM / MEM 利用率；不支持 `pmon` 的环境会自动降级为 `N/A`。
- 可在设置中开启 CPU 监控，按主机展示 CPU 利用率、占用核心数、系统内存、逻辑核心数和负载。
- CPU 卡片可折叠展示 CPU 占用最高的进程，包括 PID、用户、CPU / MEM 占用、内存、运行时间和命令行。
- 在资源概览中按机器聚合展示空闲 GPU，并按用户聚合展示 GPU 占用。 CPU 数据仅显示在各主机区域，不会加入资源概览。
- 支持选择启用的主机、手动刷新、自动刷新间隔、浅色/深色主题和语言中英文切换。
- 支持为每台主机开启状态提醒：服务器整体状态连续两次采样确认从忙碌变为空闲或从空闲变为忙碌后，发送 Windows/macOS 系统通知。
- macOS 提供始终可用的菜单栏 Panel，用于紧凑查看主机和 GPU 状态；完整详情仍可打开 Flutter 主窗口。
- 可选择在关闭窗口后继续后台运行：Windows 隐藏到系统托盘，macOS 可从菜单栏图标或 Dock 访问，监控与提醒不会中断。

## 状态变化提醒

在设置页可以点击“发送测试系统通知”验证 Windows/macOS 的本地通知和权限，然后为需要监控的服务器打开“提醒 GPU 忙闲变化”。开启提醒会自动开启自动刷新。

提醒仅在应用进程持续运行、电脑未休眠、网络和 SSH 可用且自动刷新开启时工作。首次成功查询只建立状态基线，不发送通知；之后服务器状态连续两次采样一致才会确认变化。服务器只要有一张 GPU 符合现有空闲规则，就视为整体空闲。

需要关闭主窗口后仍接收提醒时，请在“设置 → 后台运行”中打开“关闭窗口时继续后台运行”。Windows 可单击托盘图标恢复窗口，右键托盘图标后选择“退出 GPU Monitor”才会真正退出；macOS 可左键或右键菜单栏图标显示/隐藏紧凑 Panel，通过 Panel 内的窗口按钮打开完整窗口，并通过应用菜单退出。

从源码构建 Windows 版本时，系统通知插件要求 Visual Studio Build Tools 安装可选的 **C++ ATL（适用于最新 v143 生成工具，x86 和 x64）**组件；已编译的应用不要求用户单独安装该组件。
